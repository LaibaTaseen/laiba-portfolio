SafeChat AI

A cyberbullying detection system that reads a message and flags it — toxic, threat, insult, and more — using a machine learning model trained on real human-labeled comments, instead of a keyword filter anyone can dodge.

Logistic Regression + TF-IDF Flask REST API Analytics dashboard PDF reports Groq wellness chat Urdu & Roman Urdu
The Problem

Growing up in Pakistan, I saw people getting bullied constantly on WhatsApp groups and Facebook. Someone sends a hateful message, the victim feels humiliated, and nobody catches it in time. Parents have no way to know, teachers have no tools to monitor, and the victim often hesitates to tell anyone. SafeChat was built for that student.

What I Did and Decided

The first decision was how to actually detect bullying. Keyword filtering felt too easy to bypass — someone can type "stup1d" or "st*pid" or rephrase an insult entirely, and a keyword filter misses it completely. We tested this ourselves during planning and realized a filter would be useless against anyone with even basic creativity. That's why we chose a trained ML model instead — it learns the pattern and intent behind words, not just the words themselves.

Before writing any code, i downloaded the Jigsaw dataset (159,000 real human comments) from Kaggle and read through it to understand what toxic language actually looks like. That grounded everything else that followed.

i trained a Logistic Regression model. When a message comes in, it's cleaned up, converted into numbers using TF-IDF (which scores how important each word is), and the model gives a probability score across six categories: toxic, severe toxic, obscene, threat, insult, and identity hate. We used six categories instead of one "toxic or not" label because not all harmful content is the same — a threat needs immediate attention, an insult might need a softer response. Collapsing that into one label would throw away useful context.

On top of the model, we built a Flask REST API, a dashboard with real-time analytics and charts, user authentication with per-user history, PDF report generation, Urdu and Roman Urdu language support, and an AI wellness chat powered by Groq.

What Came of It

i tested it on 13 messages across English, Roman Urdu, and mixed language input, and it correctly classified all 13 — catching threats, insults, and toxic slang, while correctly passing safe messages. On the 20% test set, model accuracy ranges from 94% to 99% depending on the category, with toxic and obscene performing best.

What I'd do differently: Threat detection is the weak point — its F1 score is only 30%, because there were just 478 training examples for that category. I'd also want to fix that the model was trained on Wikipedia comments, so it sometimes struggles with casual social media slang and very short messages, and Urdu detection relies on translation, which occasionally loses nuance. Right now the system also analyzes each message in isolation without understanding the conversation around it — that's the next thing to solve.
