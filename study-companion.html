AI Study Companion

An app where students upload their lecture PDFs, PPTs, and Word documents and get automatic summaries, flashcards, quizzes, and a chat feature, all in one place, instead of switching between different tools.

React + Vite FastAPI SQLite + SQLAlchemy JWT auth Groq API
The Problem

During exam week, I realized I still had a lot of lecture slides and PDFs to study. I didn't have enough time to read every page, and using different websites for summaries, flashcards, and quizzes was frustrating.

University students often have many subjects and a lot of lecture notes, PDFs, Word documents, and PowerPoint slides to study in a short time. Reading every page isn't realistic. That's why I decided to build one application where students can upload their study materials and get everything they need in one place.

What I Did and Decided

I started with the summary feature first, because I didn't have enough time to study all the slides and documents, and there was a lot of material available. I thought that, just like me, other students needed a summary the most.

When a file is uploaded, a format-specific library pulls out the plain text — pdfplumber for PDF, python-docx for Word, python-pptx for PowerPoint — and stores it. Summaries, flashcards, and quiz questions are generated by sending that text to Groq's openai/gpt-oss-20b model. I chose this model mainly for cost (free tier) and speed, since summarizing and generating questions doesn't need a large, expensive model — it's a well-structured task, not deep reasoning. The model is easy to swap out if I ever need higher quality.

For chat, the document's text is embedded directly into the system prompt every time, with an instruction to answer only using that material, so the AI can't bring in outside knowledge. Chat history is saved to the database so it's there even after a refresh.

One real bug: when I built the "Regenerate" button for flashcards, clicking it didn't replace the old flashcards — it added new ones on top, so I'd end up with 20, then 30, old and new questions mixed together. The problem was my code was only adding new flashcards without deleting the old ones first. I fixed it with one line: delete anything already there for that document, then save the new set.

What Came of It (so far)

I've only tested this myself so far. When I uploaded a previous semester's slides, the summary included the important details from the original document — it seemed like a good way to save time compared to reading everything.

The flashcards caught something real: one flashcard asked about a point I'd skimmed past and dismissed as unimportant. When I flipped it to check the answer, I realized it actually was covered in the summary — I just hadn't noticed it mattered. The quiz helped me check whether I understood a document well enough to move on to the next one.

What I'd do differently: Fix the 12,000-character text limit so longer documents (15–20+ pages) get fully covered, and get it in front of other students instead of just testing it myself.
